Policy / effective 27 August 2026

Privacy, by absence.

SQLite Sync Guard does not collect, transmit, or sell personal information.

The CLI

The command-line tool runs locally. Scans, database paths, backup contents, manifests, and ignore files stay on your machine. It contains no telemetry or network client.

This website

This static documentation site has no analytics, cookies, advertising, account system, or third-party runtime content. Your hosting provider may process standard request metadata such as IP address and user agent for security and delivery.

Your files

You decide where exported backups are transferred. Inspect manifests before sharing because they contain the source path supplied to the tool.

Contact

Report privacy concerns through the project’s public issue tracker. Do not attach database files or secrets.
