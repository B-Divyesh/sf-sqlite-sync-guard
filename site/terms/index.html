Use backups

Keep an independent tested backup before changing sync configuration or moving database files. A safe scan means no sidecar or active lock was observed at that moment; it cannot prevent another process from starting immediately afterward.

Scope

The tool creates consistent handoff snapshots. It does not provide distributed transactions, multi-writer replication, profile merging, or recovery of a database already corrupted.
